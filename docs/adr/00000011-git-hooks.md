# 00000011. GIT HOOK KIỂM TRA ĐÚNG NỘI DUNG ĐƯỢC COMMIT, ĐƯỢC ĐẨY VÀ ĐỐI CHIẾU SAU KHI KÉO

- **Trạng thái:** Chấp nhận
- **Ngày:** 2026-10-03

## 📌 BỐI CẢNH

Kiểm tra cần phản ánh đúng nội dung được commit và đẩy, kể cả khi chỉ stage một phần tệp hoặc dùng worktree. Cấu hình GitHub và tài nguyên bên ngoài cần được đối chiếu sau khi kéo code.

## ✅ QUYẾT ĐỊNH

`scripts/git-hooks.py` quản lý các hook; `make hooks` cài vào Git common directory và cảnh báo khi `core.hooksPath` khiến Git bỏ qua chúng.

- `pre-commit`: xuất nội dung đã stage và cấu hình trong index ra thư mục tạm; chạy Prettier, `ruff format`, `ruff check` trên nội dung đó.
- `pre-push`: bỏ qua lượt chỉ đẩy tag hoặc xóa branch; chặn khi còn thay đổi chưa commit hoặc đẩy branch khác HEAD; các trường hợp còn lại chạy `make check`.
- `post-merge` và `post-rewrite` cho rebase: cài lại hook, chạy song song `make links`, `make versions`, `make org-preview` khi GitHub CLI đã đăng nhập; chỉ báo kết quả, không chặn thao tác kéo.

## 🔍 PHƯƠNG ÁN ĐÃ CÂN NHẮC

Chỉ dùng Actions không kiểm tra được trước push hoặc khi Actions tắt. Kiểm tra tệp trên đĩa sai khi index khác thư mục làm việc. Chỉ dùng `post-merge` bỏ sót việc kéo bằng rebase; Python đáp ứng việc điều phối hook và quy tắc script của tổ chức.

## ⚖️ HỆ QUẢ

Phải cài hook bằng `make hooks`; Dev Container thực hiện bước này tự động. Trước push cần commit hết hoặc `git stash -u`. Không bỏ qua hook bằng `--no-verify`. Kiểm tra sau kéo cần mạng và quyền GitHub phù hợp.
