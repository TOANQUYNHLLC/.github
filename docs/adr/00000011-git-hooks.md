# 00000011. GIT HOOK KIỂM TRA ĐÚNG NỘI DUNG ĐƯỢC COMMIT, ĐƯỢC ĐẨY VÀ ĐỐI CHIẾU SAU KHI KÉO

- **Trạng thái:** Chấp nhận
- **Ngày:** 2026-10-03

## 📌 BỐI CẢNH

Kiểm tra trước commit và push phải phản ánh đúng nội dung Git sẽ ghi, kể cả stage một phần hoặc làm việc qua worktree. Sau khi kéo nguồn, các tài nguyên trực tuyến cần được đối chiếu.

## ✅ QUYẾT ĐỊNH

`scripts/git-hooks.py` cài hook vào Git common directory bằng `make hooks` và cảnh báo khi `core.hooksPath` làm Git bỏ qua hook.

- `pre-commit` xuất nội dung đã stage cùng cấu hình trong index ra thư mục tạm, rồi kiểm tra Prettier, Ruff format và Ruff lint.
- `pre-push` chạy `make check` trên branch được đẩy; yêu cầu cây làm việc sạch và branch khớp HEAD. Lượt chỉ đẩy tag hoặc xóa branch được bỏ qua.
- `post-merge` và `post-rewrite` cho rebase cài lại hook, chạy song song `make links`, `make versions` và `make org-preview` khi GitHub CLI đã đăng nhập, chỉ báo kết quả.

Hook bỏ biến môi trường cục bộ do Git công bố khi gọi lệnh kiểm tra để các repository tạm trong tests được nhận diện theo đúng thư mục làm việc.

Nguồn của quyết định: [scripts/git-hooks.py](../../scripts/git-hooks.py), [.devcontainer/post-create.sh](../../.devcontainer/post-create.sh), [Makefile](../../Makefile).

## 🔍 PHƯƠNG ÁN ĐÃ CÂN NHẮC

Xuất index giúp kiểm tra đúng nội dung được commit. Kiểm tra trước push bổ sung phản hồi tại máy cả khi Actions tắt. Các hook sau kéo bao quát Merge và Rebase mà không chặn việc nhận nguồn vì lỗi dịch vụ ngoài.

## ⚖️ HỆ QUẢ

Người đóng góp cài hook sau clone; Dev Container thực hiện bước này khi tạo môi trường. Trước push cần commit hết hoặc `git stash -u`. Không dùng `--no-verify` để bỏ kiểm tra. Các lượt đối chiếu sau kéo cần mạng.
